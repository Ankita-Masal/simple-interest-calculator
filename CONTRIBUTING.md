# Contributing to Simple Interest Calculator

Thank you for your interest in this project!

**All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.**

## How to contribute
1. Fork the repository.
2. Create a new branch for your change: `git checkout -b my-change`.
3. Make your changes and commit them with a clear message.
4. Push the branch to your fork: `git push origin my-change`.
5. Open a pull request describing what you changed and why.

## Reporting bugs
Open an issue and include the steps to reproduce the problem, the expected result, and the actual result.

## Suggesting enhancements
Open an issue describing your idea and how it would improve the calculator.

## Code of Conduct
By taking part in this project you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
