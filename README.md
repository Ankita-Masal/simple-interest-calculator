# Simple Interest Calculator

**Project name:** Simple Interest Calculator

A small Bash command-line calculator that computes simple interest from user input.

## About the project
Simple interest is calculated with the formula:

```
Simple Interest = (Principal x Rate x Time) / 100
```

The script `simple-interest.sh` asks the user for three input fields:

- **Principal** – the amount of money borrowed or invested
- **Rate of interest** – the yearly interest rate in percent
- **Time period** – the duration in years

It then prints the simple interest.

## How to run
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example
```
Enter the principal amount: 10000
Enter the rate of interest (% per annum): 5
Enter the time period (in years): 2
Simple Interest = 1000.00
```
